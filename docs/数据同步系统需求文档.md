# 项目需求：SQL Server数据库数据同步系统

## 一、项目概述
开发一个基于Python的SQL Server数据库数据同步工具，实现从源数据库到目标数据库的增量/全量数据同步功能。

## 二、技术栈要求
- **开发语言**：Python 3.8+
- **数据库**：SQL Server
- **数据库驱动**：pyodbc 或 pymssql
- **配置管理**：JSON配置文件
- **环境隔离**：Python虚拟环境（venv）
- **日志记录**：logging模块

## 三、功能需求

### 3.1 核心功能
1. **数据库连接管理**
   - 读取JSON配置文件中的数据库连接信息
   - 建立源数据库和目标数据库的连接
   - 连接池管理和异常重试机制

2. **数据同步功能**
   - 支持全量同步和增量同步模式
   - 根据配置文件中的表列表进行批量同步
   - 保持数据完整性和事务一致性
   - 支持大批量数据的分批处理

3. **配置管理**
   - 数据库连接配置文件（JSON格式）
   - 表同步配置文件（JSON格式），包含：
     - 需要同步的表名列表
     - 同步模式（全量/增量）
     - 同步策略（覆盖/追加）
     - 批处理大小配置

4. **错误处理与日志**
   - 详细的执行日志记录
   - 同步失败时的错误捕获和回滚
   - 同步进度跟踪和统计信息输出
   - 日志文件按日期归档

### 3.2 扩展功能（可选）
- 同步前数据备份功能
- 数据冲突检测和解决策略
- 支持自定义字段映射
- 邮件/消息通知功能
- 同步任务定时调度（使用APScheduler）

## 四、配置文件设计

### 4.1 数据库连接配置（db_config.json）
```json
{
  "source_database": {
    "server": "source_server",
    "database": "source_db",
    "username": "user",
    "password": "password",
    "driver": "ODBC Driver 17 for SQL Server"
  },
  "target_database": {
    "server": "target_server",
    "database": "target_db",
    "username": "user",
    "password": "password",
    "driver": "ODBC Driver 17 for SQL Server"
  },
  "sync_settings": {
    "batch_size": 1000,
    "retry_times": 3,
    "retry_interval": 5
  }
}
```

### 4.2 表同步配置（tables_config.json）
```json
{
  "tables": [
    {
      "table_name": "table1",
      "sync_mode": "full",
      "sync_strategy": "overwrite",
      "primary_key": "id",
      "enabled": true
    },
    {
      "table_name": "table2",
      "sync_mode": "incremental",
      "sync_strategy": "append",
      "primary_key": "id",
      "last_sync_field": "update_time",
      "enabled": true
    }
  ]
}
```

## 六、开发步骤
1. **环境准备**
   - 创建Python虚拟环境
   - 安装必要依赖（pyodbc, python-dotenv等）

2. **配置管理模块**
   - 实现配置文件的读取和验证
   - 配置参数的校验和默认值处理

3. **数据库连接模块**
   - 实现数据库连接池
   - 连接异常处理和重试机制
   - 连接测试功能

4. **数据同步核心模块**
   - 表结构同步（如需要）
   - 全量数据同步实现
   - 增量数据同步实现
   - 批量数据处理优化
   - 事务管理和错误回滚

5. **日志和监控模块**
   - 日志记录功能
   - 同步进度展示
   - 统计信息收集

6. **主程序和测试**
   - 主程序入口开发
   - 单元测试编写
   - 集成测试

## 七、非功能需求
- **性能**：单表百万级数据同步时间控制在合理范围
- **可靠性**：网络中断等异常情况下的数据一致性保障
- **可维护性**：代码结构清晰，注释完整
- **可扩展性**：易于添加新的同步策略和功能
- **安全性**：敏感信息（密码）的加密存储建议
