# GUI 界面使用说明

## 概述

数据同步系统现在提供了现代化的图形用户界面（GUI），采用三步向导式设计，操作简单直观。

## 启动方式

### 方式一：使用启动脚本（推荐）

双击运行 `run_gui.bat` 文件即可启动 GUI 应用。

### 方式二：直接运行 Python 脚本

在项目根目录下执行：

```bash
python src/gui_app.py
```

## 界面功能

### 步骤 1：选择配置

- **配置选择下拉列表**：显示所有可用的配置文件
- **配置详情**：显示选中配置的名称、描述和文件名
- **下一步按钮**：确认选择后进入同步步骤
- **退出按钮**：退出应用

**操作流程**：
1. 从下拉列表中选择一个配置文件
2. 查看配置详情确认选择
3. 点击"下一步"按钮

### 步骤 2：执行同步

- **当前配置显示**：显示正在使用的配置名称
- **当前表显示**：显示正在同步的表名
- **进度条**：显示整体同步进度
- **进度文本**：显示已完成的表数量（如：3/5 表）
- **执行日志**：实时显示同步过程的详细日志
- **取消按钮**：中断正在执行的同步任务
- **上一步按钮**：返回配置选择步骤

**操作流程**：
1. 进入此步骤后自动开始同步
2. 观察进度条和日志了解同步状态
3. 可以随时点击"取消"按钮中止同步
4. 同步完成后自动跳转到结果页面

### 步骤 3：查看结果

- **时间统计**：
  - 开始时间
  - 结束时间
  - 总耗时
- **表统计**：
  - 总表数
  - 成功（绿色显示）
  - 失败（红色显示）
  - 跳过（灰色显示）
  - 同步行数
- **详细日志**：显示每张表的同步详细信息
- **重新开始按钮**：返回步骤 1，重新开始新的同步任务
- **退出按钮**：退出应用

**详细日志包含**：
- 表名和状态符号（✓ 成功 / ✗ 失败 / ○ 跳过）
- 源数据行数
- 主表同步详情（插入行数、跳过重复数）
- 关联表 WFC_PROCESS 同步详情（如适用）
- 错误信息（如果失败）

## 界面特性

### 现代化设计

- **暗色主题**：默认使用暗色主题，保护视力
- **圆角设计**：按钮和输入框采用圆角设计
- **流畅动画**：按钮 hover 效果和进度条动画
- **高对比度**：重要信息使用颜色区分（成功绿色、失败红色）

### 响应式界面

- **实时日志更新**：同步过程中实时显示日志
- **进度条动画**：平滑的进度条动画效果
- **自动滚动**：日志自动滚动到最新内容
- **非阻塞操作**：同步在后台线程执行，界面不卡顿

### 用户友好

- **一键操作**：只需选择配置，点击下一步即可
- **随时取消**：可以随时中止同步任务
- **错误提示**：清晰的错误信息显示
- **状态反馈**：每步都有明确的状态提示

## 技术实现

### 使用技术栈

- **GUI 框架**：CustomTkinter 5.2.0
- **主题模式**：Dark（暗色主题）
- **并发处理**：使用 threading 实现后台同步
- **日志队列**：使用 queue.Queue 实现线程间通信

### 架构设计

```
DataSyncApp (主应用类)
├── Step 1 Frame (配置选择)
│   ├── 配置下拉列表
│   ├── 配置详情显示
│   └── 导航按钮
├── Step 2 Frame (执行进度)
│   ├── 进度信息面板
│   ├── 进度条
│   ├── 日志文本框
│   └── 控制按钮
├── Step 3 Frame (结果展示)
│   ├── 统计信息面板
│   ├── 详细日志
│   └── 操作按钮
└── 后台同步线程
    ├── 配置加载
    ├── 数据库连接
    └── 数据同步
```

## 与原命令行模式对比

| 特性 | 命令行模式 | GUI 模式 |
|------|-----------|---------|
| 操作复杂度 | 中等 | 简单 |
| 视觉体验 | 纯文本 | 现代化界面 |
| 实时反馈 | 文本输出 | 可视化进度 |
| 中断操作 | Ctrl+C | 取消按钮 |
| 结果展示 | 文本摘要 | 图表+详细日志 |
| 多任务操作 | 不支持 | 支持重新开始 |

## 常见问题

### Q: GUI 窗口无法启动？

**A**: 请确保已安装 CustomTkinter：
```bash
pip install customtkinter
```

### Q: 配置文件列表为空？

**A**: 请检查 `config/table_configs` 目录下是否存在配置文件。配置文件必须包含 `name` 和 `tables` 字段。

### Q: 同步过程中界面卡住？

**A**: 同步在后台线程执行，界面不会卡住。如果长时间无响应，可能是网络或数据库连接问题。

### Q: 如何切换主题？

**A**: 修改 `src/gui_app.py` 文件中的主题设置：
```python
ctk.set_appearance_mode("light")  # 改为亮色主题
```

## 注意事项

1. **不要关闭窗口**：同步过程中不要强制关闭窗口，应使用"取消"按钮
2. **数据库连接**：确保数据库配置正确且可访问
3. **权限要求**：确保有足够的数据库权限（SELECT、INSERT、TRUNCATE 等）
4. **网络稳定**：确保网络连接稳定，避免同步中断
